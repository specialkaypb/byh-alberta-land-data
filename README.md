# BYH clickable climate zones (live)

Koppen-Geiger climate zones at 1 km for the whole world, as Google Earth files that load when you zoom in, with the BYH zone cards. The BYH Property Diagnosis Filestream links here.

Source: Beck, H.E., et al. (2023). High-resolution (1 km) Koppen-Geiger maps for 1901-2099 based on constrained CMIP6 projections. Scientific Data 10, 724. The 1991-2020 map. CC BY 4.0. Class rules: Beck et al. (2018), Table 2.

This branch is replaced in full whenever the zones or cards are rebuilt.
